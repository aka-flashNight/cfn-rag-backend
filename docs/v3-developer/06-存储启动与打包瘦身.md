## 1. 存储层（仅 SQLite + 本地文件）

### 1.1 NPC 状态（services/npc/manager.py，修 E1）

```python
class NPCManager:
    """进程内单例：
    - 启动时一次性读 npc_state_db.json 入内存 dict（修『每请求全量读 JSON』）。
    - 读写经 asyncio.Lock（读多写少，单锁即可）。
    - update_favorability 只改内存 + 置 dirty；后台 5s 防抖落盘（tmp+replace 原子写）。
    - 进程退出前 flush。
    - npc_state_db.json 条目新增可选字段 appearance: str（形象描述文本，07 使用），
      读取时缺省容忍，写回时保留未知字段（forward-compatible）。"""
```

### 1.2 会话存储（services/memory/store.py，修 E4）

- 单连接 `sqlite3.connect(check_same_thread=False)` + `threading.Lock` + WAL 模式；不再每操作新建连接。
- 表结构沿用：chat_history / sessions / session_summaries / session_task_drafts / ask 计数器。
- **统一返回 dataclass（ChatMessage）**，消灭「dict 列表 vs dataclass 双形状」；API 层类型标注与实现一致。
- 草案过期：沿用「连续 N 次 ask 未触碰任务工具即删除」，N 由 `draft_keep_turns` 配置；`bargain_count` 独立成列，不再混进草案 JSON（D5）。

### 1.3 摘要（services/memory/summarize.py，修 E2）

- 保留「达到间隔触发滚动摘要」逻辑；改为**有界队列 + 单 worker 协程**串行执行（并发上限 1，带超时 60s，失败重试 1 次后放弃本轮）。
- LLM 调用走统一 LLMClient（`purpose="summary"`，不带图、不带思考参数之外的特殊处理）。

### 1.4 代理配置（修 E3）

- `proxy_url` 只作为 LLMClient 构造参数（httpx 客户端级），**禁止写 os.environ**。前端改动：无（仍按请求传参）。

### 1.5 删除

`services/storage/`（Cache/DB/Vector 三抽象及 PG/Qdrant/Redis 实现）、`services/session_heartbeat.py`、`check_idempotent`、Redis 相关全部（E5/B6）。

## 2. 启动优化（core/startup.py 重写）

```
启动序列（全部并行 gather，打印改 logging）：
├─ OnnxEmbedder 预载 + 预热          (~0.5s)
├─ VectorStore.load（指纹匹配则 <1s）  │ 不匹配 → 后台构建 ≤25s，期间检索降级 BM25-only
├─ GameDataRegistry 加载
├─ NPCManager 加载
├─ 任务文件 ensure（agent_tasks/agent_text/list.xml 注册，沿用现逻辑）
```

- 目标：**索引已建时从进程启动到 /api/ask 可服务 ≤ 5s**（不含 exe 自解压）。
- 删除：立绘包解压任务、npc_state_db 从 backup 复制的连锁脚本（保留 backup 复制本身，逻辑简化）、全部 print（F4，改 logging，local 也输出到控制台+文件 `cfn-rag.log`）。
- `main.py` 的 `reload=True` 硬编码删除（F3）；`main.py` 与 launcher 统一 `reload=False`。
- `LatencyTracker` 保留，done 事件附 usage。

## 4. PyInstaller 打包（scripts/build_exe.py 重写）

- onefile；hidden imports：`onnxruntime`、`tokenizers` 及 uvicorn 标准件；显式 exclude：`torch`、`transformers`、`llama_index`、`langchain`、`numpy.tests` 等。
- 打包内容：`dist/`（前端）、`models/bge-small-zh-v1.5-onnx-int8/`、`backup_resources/`。**不再打**：`tools/`（ffdec 删除）、原始 HF 模型目录、`scripts/`、evals、tests。
- **体积预算**（验收时核对）：onnxruntime ~50MB + Python/FastAPI 运行时 ~60MB + int8 模型 ~25MB + 前端 ~5MB → 单 exe 目标 ≤ 160MB；Full 版 zip 额外带精简 resources。
- `launcher.py` 保留：单实例互斥、起后端、静态服务 + `/api` 反代（SSE 流式转发保留）；删除立绘解压/SWF 导出相关入口（对应前端按钮由 09 标注移除）。
