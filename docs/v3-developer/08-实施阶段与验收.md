## 风险与注意事项（实施时必读）

1. **GLM-5.3-Flash 思考参数名待官方复核**（调研原文标注）：若 `reasoning_effort` 报错，降级链会自动退到只发 `thinking.type=enabled`——这是设计内行为，不要当作 bug 修掉降级链。
2. **DeepSeek-V4-Flash-Vision-Exp 的思考参数与视觉声明**未在官方页核实差异，接入时以实测为准；异常就走降级链。
3. **meta 协议依赖模型听话程度**：对跟随差的模型，可在 prompt 加一行 JSON 示例；解析器已做全容错，最坏退化为「无情绪前置的纯聊天」，功能不崩。
4. **中间结果话术**是产品级规则：宁可不说，不可报数字。
5. **confirm 丢正文重生成**是稀有路径，但必须测到（mock 一次）。
6. requirements-dev 的 torch 装 CPU 版，别污染运行时 venv。
