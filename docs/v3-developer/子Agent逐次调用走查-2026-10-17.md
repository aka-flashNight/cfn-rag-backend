### 走查脚本自身踩的两条（可复用结论）

1. `LLMClient.chat_stream` 本体是**带 yield 的 `async def`**＝异步生成器函数，调用它直接得到异步迭代器；
   包装器若写成「`async def` + 内部 `async for` 但**不 yield**」就退化成了协程函数，
   调用方 `async for ev in stream` 立刻报 `'async for' requires an object with __aiter__ method, got coroutine`。
   第一次运行（16:12）聊天层两轮就是这样崩的，**异常发生在发 HTTP 之前，没有浪费任何调用**。
2. 每次运行要用**独立临时目录**：对话改写作业按 `(slot, task_id)` 幂等，
   若 `memory.db` 里留着上一轮同 task_id 的 `written` 记录，触发一会「一查就已写完」而根本不重新调用，
   拿到的是假数据。

### 本条链路的两个问题

1. **28.0s 空窗在稳态成立。** 索引已命中缓存，28s 全部是三次串行的 LLM 调用（8.5s 静默路由轮

   只在**看到 `intermediate` 事件**时才说（`services/orchestrator/merge.py:263`），
   而 `intermediate` **只有 `task_runner` 会发**（`services/subagents/task_runner.py:189/203`），
   `SearchRunner` 从不发——所以检索路径没有任何提前说话的机会，玩家只有一条状态行。
   本批**未改代码**，登记为待作者定夺项（要治就得让检索路径也出一个 intermediate，或给路由轮一个非静默例外）。
2. **产品 usage 少计。** 本轮真实合计 prompt 16,464／completion 695，
   SSE `done` 里的产品口径是 prompt 12,260／completion 306（只含两次 chat 调用），
   少计 prompt 4,204（25.5%）、completion 389（56.0%）。是否把子 Agent 并进 `calls` 待作者定。

### 落盘结果与两处偏离

`applied=1 rejected=2`，载荷 `{'changed': True, 'applied': ['新增日常对话组 agent_1：3 行'], 'rejected': [...]}`：

- 拒绝原因两条同族：**「编号 8：第 2 行说话人「玩家」不在允许范围内（只能是 Andy Law、$PC 或本组原有说话人）」**
  ／**「编号 12：第 5 行说话人「玩家」…」**——模型用自然语言「玩家」当说话人，而不是 `$PC`。
  校验闸按预期挡下并回文案，两条组没落进去。

> 不过丑话说在前头，自己人的身份不代表你可以偷懒，活儿干砸了我照样骂你。

  机制侧核对＝这不是模型任性：`DialogueRunner` 的工具表只有 `search_npc_dialogues` / `edit_npc_dialogues`

## 四、另一条抓到的缺陷：该路由检索时没路由，还把设定说成没听过

同一会话前一轮（16:19 那次运行的 R1，玩家问「堕落城深处…铁枪会最近在那边活动得多吗？」）：

- 调用 1 次 `chat_stream`／purpose=chat，7679ms、首字 7079ms、prompt 6585／completion 88／cached 0，
  工具表 4 个都在，**返回的工具调用＝无**，整回合 8.6s 直接出台词。
- 台词（情绪 严肃）：「**铁枪会？这名字我可没听说过**，你不会是道听途说来的吧。堕落城那边如今是黑铁会的地盘，
  这帮人用冷兵器，下手又快又狠，外环最近还闹出不少浮士德兄弟的凶案……」

核过语料：`data/glossary/铁枪会.json`、`data/dialogues/enemy_dialogues.xml:811`、
`data/intelligence/硬化僵尸情报.txt`、`data/intelligence/酒保线报：黑铁会崛起于乡间.txt` 全都写着铁枪会。
「堕落城深处的情形」这类问题里，聊天层的**常驻 Tier-1 检索块**（`services/orchestrator/context.py:495`）
给到的材料不含该词条时，模型没有走 `route_search` 查证，而是**否认这个组织存在**——
比上一批记录的「称呼幻觉」更严重一档：那是造名字，这是把真实存在的势力说成没听过。
属**路由依从率＋知识供给**两侧问题，本批只取证不施工。
